# 40 — البـاء (al-Bāʾ)

> **Video:** [الباء](https://www.youtube.com/watch?v=WYfbDsNvWAs)
> **Book:** حروف الجر — الأول: الباء (p.42–43)
> **Topic:** The first preposition. Its core meaning is **الإلصاق** (attachment), and the book parses باء + its noun by the **object-type** it corresponds to.

---

## معنى الباء

> **معنى الباءِ: الإلصاقُ** — *attachment / contact* (اتّصالُ شيءٍ بشيءٍ). This is its root sense, from which the others branch.

## إعراب الباء مع مجرورها — by object-type
The باء-phrase is read as standing for one of the complements:

| Sense | Shāhid |
|---|---|
| **المفعول المطلق** | ﴿خُذِ الكتابَ **بقوّةٍ**﴾ |
| **المفعول به** | ﴿فلمّا ذهَبوا **به**﴾ |
| **المفعول فيه** — مكان | ﴿ولقد نَصَرَكمُ اللهُ **ببدرٍ**﴾ |
| **المفعول فيه** — زمان | ﴿يُسبِّحونَ له **بالليلِ والنهارِ**﴾ |
| **المفعول له** | ﴿فأهلَكْناهم **بذنوبِهم**﴾ |
| **المفعول معه** | ﴿وقد دَخَلوا **بالكفرِ**﴾ |
| **الحال** | ﴿ادخُلوها **بسلامٍ** آمنينَ﴾ |
| **التمييز** | يَملأُ الخُلُقُ الحَسَنُ الميزانَ **بالحسناتِ** |
| **الآلة** | ﴿يكتبونَ الكتابَ **بأيديهم**﴾ |

## التعدية (باء النقل)
The باء can be **transitivising** — turning an intransitive verb into a transitive one, with a sense close to **التصيير**:
- ﴿**ذهَبَ** اللهُ **بـ**نورِهم﴾ = *adhhaba* (He took away their light) — **ذهب به** ≈ *made it go*.

> *Nuance:* بـ for **مصاحبة** (accompaniment) vs بـ for **تعدية**: "دخلتُ **بـ**زيدٍ" (mostly accompaniment) — but ﴿ذهب بنورهم﴾ is **not** accompaniment (He didn't go *with* them), so here it is **transitivising**.
